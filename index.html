HR System

ຂໍ້ມູນພະນັກງານ, ເວລາເຮັດວຽກ, ລາພັກ, ເງິນເດືອນ ແລະ ລາຍງານ

ເຄື່ອງເຊີບເວີຕິດຕັ້ງເຄື່ອງດຽວ ພ້ອມຖານຂໍ້ມູນ ~450 MB ເຄື່ອງລູກຕິດຕັ້ງທຸກເຄື່ອງທີ່ໃຊ້ງານ ~43 MB

Face Scan

ເຄື່ອງສະແກນໜ້າລົງເວລາ ສົ່ງເວລາເຂົ້າ HR System ອັດຕະໂນມັດ

ເຄື່ອງສະແກນໃໝ່ຕິດຕັ້ງພ້ອມຖານຂໍ້ມູນ ~540 MB ໂປຣແກຣມຢ່າງດຽວເຄື່ອງທີ່ມີຖານຂໍ້ມູນແລ້ວ ~130 MB

ຂັ້ນຕອນຕິດຕັ້ງ

  1. ຕິດຕັ້ງ HR System ເຄື່ອງເຊີບເວີ ກ່ອນ (ເຄື່ອງດຽວ, ໃຊ້ສິດ admin)
  2. ຕິດຕັ້ງ HR System ເຄື່ອງລູກ ທຸກເຄື່ອງທີ່ໃຊ້ງານ ແລ້ວນຳເຂົ້າໄຟລ໌ການເຊື່ອມຕໍ່ຈາກເຊີບເວີ
  3. ຖ້າໃຊ້ເຄື່ອງສະແກນໜ້າ: ຕິດຕັ້ງ Face Scan ເຄື່ອງສະແກນໃໝ່ ທີ່ເຄື່ອງສະແກນ
  4. ໂປຣແກຣມອັບເດດເອງເມື່ອມີເວີຊັນໃໝ່ (ຕ້ອງມີອິນເຕີເນັດ)
