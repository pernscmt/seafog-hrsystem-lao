ມີຄຳຖາມ?

ຂໍ້ມູນຂອງບໍລິສັດເກັບໄວ້ໃສ?

ເກັບໃນເຄື່ອງເຊີບເວີຂອງທ່ານເອງ (ຖານຂໍ້ມູນ PostgreSQL) ບໍ່ໄດ້ສົ່ງຂຶ້ນອິນເຕີເນັດ ແລະ ສຳຮອງ / ກູ້ຄືນໄດ້ຈາກໃນໂປຣແກຣມ

ໃຊ້ໄດ້ຈັກເຄື່ອງ?

ເຄື່ອງລູກບໍ່ຈຳກັດຈຳນວນ ທຸກເຄື່ອງທີ່ຢູ່ໃນວົງ LAN ດຽວກັບເຄື່ອງເຊີບເວີ ໃບອະນຸຍາດຄິດຕາມຈຳນວນພະນັກງານ ບໍ່ແມ່ນຈຳນວນເຄື່ອງ

ໝົດທົດລອງແລ້ວ ຂໍ້ມູນຈະຫາຍບໍ?

ບໍ່ຫາຍ ໂປຣແກຣມຈະເປັນໂໝດເບິ່ງຢ່າງດຽວ (ເບິ່ງ / ພິມ / ສຳຮອງໄດ້) ຈົນກວ່າຈະນຳເຂົ້າໃບອະນຸຍາດ ແລ້ວໃຊ້ຕໍ່ໄດ້ທັນທີ

ຕ້ອງມີອິນເຕີເນັດບໍ?

ໃຊ້ງານປະຈຳວັນໃນວົງ LAN ໄດ້ໂດຍບໍ່ຕ້ອງມີອິນເຕີເນັດ ອິນເຕີເນັດໃຊ້ສຳລັບອັບເດດໂປຣແກຣມເທົ່ານັ້ນ

Face Scan ໃຊ້ໂດຍບໍ່ມີ HR System ໄດ້ບໍ?

ໄດ້ ນຳເຂົ້າລາຍຊື່ພະນັກງານຈາກ Excel ເບິ່ງລາຍງານໃນໂປຣແກຣມ ແລະ ສົ່ງເວລາສະແກນອອກເປັນ Excel/CSV ຫຼື ສົ່ງເຂົ້າລະບົບເງິນເດືອນອື່ນ

ເປັນຫຍັງ Windows ຈຶ່ງເຕືອນຕອນດາວໂຫຼດ?

Windows ເຕືອນທຸກໂປຣແກຣມໃໝ່ທີ່ຍັງມີຄົນດາວໂຫຼດໜ້ອຍ ບໍ່ແມ່ນໄວຣັດ ໄຟລ໌ດາວໂຫຼດຈາກ GitHub ຂອງເຮົາໂດຍກົງ ໃນ Edge ກົດ … → Keep → ▾ ໃນປຸ່ມ Delete → Keep anyway ແລະ ຕອນເປີດໄຟລ໌ ກົດ More info → Run anyway (ເບິ່ງຂັ້ນຕອນໃນສ່ວນ ດາວໂຫຼດ)

ສັ່ງຊື້ ແລະ ຈ່າຍເງິນແນວໃດ?
